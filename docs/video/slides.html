The gap between appointments

  • People with Parkinson's see a neurologist every few months.
  • In between, “how was I when the medication wore off?” is answered from memory.
  • At the bedside, doctors ask for 10 fast, big finger taps and look for taps that get slower and smaller.
  • Phone screen-tap tests see speed — not how wide the fingers open.
  • TapTen uses a fixed 10-second window so every test is comparable.

How accurate? A ground-truth benchmark

No patient videos yet, so: a 3D hand animated with a known tap schedule → rendered → the same model and analysis code as the app.
